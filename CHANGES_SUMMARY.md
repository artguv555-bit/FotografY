## 🔧 Технические детали

### JSON формат
Каждый файл перевода - это объект вида:
```json
{
  "раздел": {
    "ключ": "значение"
  }
}
```

### Система работает:
1. При загрузке страницы - определяет язык
2. Для каждого элемента с `data-key` - подставляет перевод
3. При нажатии на переключатель - обновляет весь контент
4. Сохраняет выбор в `localStorage`

### Поддерживаемые атрибуты:
- `data-key="раздел.ключ"` - для обычного текста
- `data-placeholder-key="раздел.ключ"` - для placeholder в полях ввода
