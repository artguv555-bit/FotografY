## 🌐 Мультиязычность

Сайт поддерживает **3 языка**:
- **РУ** (Русский) — по умолчанию
- **EN** (Английский)
- **HY** (Армянский)

### Как добавить новый текст на все языки:

1. **Откройте** `i18n/ru.json`
2. **Добавьте** ключ со значением:
```json
{
  "newSection": {
    "title": "Новый заголовок"
  }
}
```

3. **Повторите** то же самое в `i18n/en.json` и `i18n/hy.json`

4. **В HTML используйте:**
```html
<h2 data-key="newSection.title">Новый заголовок</h2>
```

## 🐛 Частые ошибки

### ❌ Проблема: Фото не загружаются

**Решение:**
1. Проверьте пути в `index.html` (должны быть `images/portfolio-*.jpg`)
2. Убедитесь, что фотографии в папке `images/`
3. Проверьте расширения (должны быть `.jpg`, не `.JPG`)

### ❌ Проблема: Форма не отправляется

**Решение:**
1. Форма работает только локально (на http://localhost:8000 или выше)
2. При публикации нужен backend для обработки данных
3. Можете добавить сервис вроде Formspree или Basin

### ❌ Проблема: Язык не переключается

**Решение:**
1. Убедитесь, что подключен `js/i18n.js` перед `js/main.js`
2. Проверьте консоль браузера (F12 → Console) на ошибки
3. Убедитесь, что все JSON-файлы в папке `i18n/`

### ❌ Проблема: Лайтбокс не работает

**Решение:**
1. Убедитесь, что `js/main.js` подключен
2. Проверьте, что фотографии загружены
3. Откройте консоль (F12) и проверьте ошибки
