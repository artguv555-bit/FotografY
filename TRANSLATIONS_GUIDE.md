## 🌐 Как работает система переводов

### Архитектура I18n

Система использует класс `I18n`, который:
1. **Обнаруживает язык** - проверяет `localStorage.lang` или использует русский по умолчанию
2. **Загружает переводы** - использует встроенные объекты (не требует fetch)
3. **Обновляет контент** - заменяет текст элементов на основе атрибутов `data-key`

### Как использовать переводы в HTML

#### Способ 1: Переводимый текст
```html
<h1 data-key="hero.title">Оригинальный текст на русском</h1>
```

#### Способ 2: Placeholder для форм
```html
<input 
  type="text" 
  data-placeholder-key="contact.form_name_placeholder"
  placeholder="Как к вам обращаться"
/>
```

### Как добавить новый перевод

1. **В файле `i18n/ru.json`** добавьте ключ:
```json
{
  "mySection": {
    "myKey": "Текст на русском"
  }
}
```

2. **В файле `i18n/en.json`**:
```json
{
  "mySection": {
    "myKey": "Text in English"
  }
}
```

3. **В файле `i18n/hy.json`**:
```json
{
  "mySection": {
    "myKey": "Տեքստ հայերեն"
  }
}
```

4. **В файле `js/i18n.js`** добавьте объекты перед класс `I18n`:
```javascript
const translationsRu = {
  // ... существующие переводы
  "mySection": {
    "myKey": "Текст на русском"
  }
};

const translationsEn = {
  // ... существующие переводы
  "mySection": {
    "myKey": "Text in English"
  }
};

const translationsHy = {
  // ... существующие переводы
  "mySection": {
    "myKey": "Տեքստ հայերեն"
  }
};
```

5. **В HTML** используйте ключ:
```html
<p data-key="mySection.myKey">Это изменится при переключении языка</p>
```

## 💾 Хранение выбранного языка

Выбранный язык сохраняется в `localStorage` с ключом `lang`:
```javascript
localStorage.getItem('lang');  // Получить текущий язык
localStorage.setItem('lang', 'en');  // Установить английский
```

## 🔌 API класса I18n

### Методы

```javascript
// Установить язык программно
i18n.setLanguage('en');

// Получить перевод
const text = i18n.t('hero.title');

// Получить текущий язык
console.log(i18n.currentLang);

// Обновить всю страницу
i18n.updatePage();
```

### Свойства

```javascript
i18n.currentLang;        // Текущий язык
i18n.translations;       // Объект со всеми переводами
```

## 🐛 Частые проблемы

### Перевод не меняется
- ✓ Убедитесь, что элемент имеет атрибут `data-key`
- ✓ Проверьте правильность пути к ключу (например, `hero.title`)
- ✓ Очистите кеш браузера (Ctrl+Shift+Del)

### JSON показывает ошибку
- ✓ Проверьте скобки: каждый `{` должен иметь `}`
- ✓ Убедитесь, что после последнего элемента нет запятой
- ✓ Используйте онлайн валидатор JSON: https://jsonlint.com/

### Кириллица/армянские символы не отображаются
- ✓ Убедитесь, что `<meta charset="UTF-8">` есть в `<head>`
- ✓ Проверьте, что файлы сохранены в кодировке UTF-8

## 🚀 Как добавить новый язык

1. Создайте новый файл `i18n/xx.json` (где `xx` - код языка)

2. Скопируйте структуру из `i18n/ru.json` и переведите все значения

3. В `js/i18n.js` добавьте объект переводов:
```javascript
const translationsXx = { ... };
```

4. В конструкторе класса добавьте язык:
```javascript
this.translations = {
  ru: translationsRu,
  en: translationsEn,
  hy: translationsHy,
  xx: translationsXx  // Новый язык
};
```

5. В `index.html` добавьте кнопку:
```html
<button class="lang-btn" data-lang="xx" title="Название языка">XX</button>
```

6. В методе `detectLanguage()` обновите проверку:
```javascript
if (saved && ['ru', 'en', 'hy', 'xx'].includes(saved)) {
  return saved;
}
```
